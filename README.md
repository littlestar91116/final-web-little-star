# final-web-little-star

## Little Star Learning Center — Sistem Manajemen Sekolah Inklusif & Galeri Interaktif

Sistem aplikasi web modern berbasis **React 19**, **Vite**, **TailwindCSS**, dan **Motion** untuk **Little Star Learning Center**:
- 🌟 **Layar Awal**: Galeri foto dan video beranimasi dengan lightbox player dan penyaringan kategori.
- 📝 **Pendaftaran Siswa Baru (PSB Online)**: Formulir pendaftaran multi-program (Sekolah Pagi, Terapi Sensori & Wicara, DayCare, Shadow Teacher) dengan integrasi otomatis ke modul internal.
- 💬 **Konsultasi WhatsApp**: Tautan terintegrasi dengan pesan template otomatis.
- 👑 **Manajemen Super Admin & CMS Website**:
  - Unggah foto/video dokumentasi baru
  - Fitur Take Down & publikasi media
  - Master Pengaturan Website (mengubah identitas sekolah, teks hero, biaya pendaftaran, rekening bank, nomor kontak, jam operasional, ticker pengumuman, dan mode sistem).
- 📊 **Modul Akademik & Siswa**: Dashboard Wali Murid, Guru, Kepala Sekolah, Admin PSB, Rekam SDR, Jadwal & Absensi, Keuangan & SPP.

---

### Cara Menjalankan Project:
1. Pastikan Node.js terinstal.
2. Pasang dependensi:
   ```bash
   npm install --legacy-peer-deps
   ```
3. Jalankan server lokal:
   ```bash
   npm run dev
   ```
4. Buka di browser: `http://localhost:3000`
